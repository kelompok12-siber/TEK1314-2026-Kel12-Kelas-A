root@192.168.56.10's password:

Diambil: 20 Oktober 2026 (sekitar 12.05 WIB), dari Windows host (192.168.56.1) ke Target Node 192.168.56.10
Screenshot: 07-ssh-root-login-gagal.png
Kontrol terkait:
- A1 - Login root SSH ditolak (PermitRootLogin no).
- A2 - Koneksi diputus setelah percobaan autentikasi gagal (MaxAuthTries 3).
Catatan: dengan PermitRootLogin no, root ditolak walaupun passwordnya benar. User biasa (kel-12) tetap dapat login lewat jalur host-only.
